การอ้างอิง APA 7: Cerulli, A., Tessa, B., & La Selva, G. (2026). Dark personality traits and online toxicity: Linking self-reports to Reddit activity. Computers in Human Behavior, 174, 109085. https://doi.org/10.1016/j.chb.2026.109085

1. สาระสำคัญและวัตถุประสงค์วิจัย

งานวิจัยนี้ทำการเชื่อมโยงระหว่างแบบประเมินบุคลิกภาพด้านมืด Dark Triad (Machiavellianism, Narcissism, Psychopathy) เข้ากับพฤติกรรมการโพสต์และการแสดงความคิดเห็นจริงบนแพลตฟอร์ม Reddit ในระยะยาว โดยใช้ Natural Language Processing และการจำแนกความรุนแรงของข้อความ (toxicity classification) เพื่อศึกษาว่าบุคลิกภาพที่แฝงอยู่ส่งผลต่อพฤติกรรมในพื้นที่ดิจิทัลอย่างไร

2. ระเบียบวิธีวิจัยและกลุ่มตัวอย่าง

มิติระเบียบวิธีรายละเอียด
กลุ่มตัวอย่างผู้ใช้งาน Reddit จำนวน 842 คน ที่ยินยอมให้เชื่อมโยงผลแบบสำรวจกับประวัติการโพสต์ย้อนหลัง
วิธีการรวบรวมข้อมูลแบบสอบถาม Dirty Dozen ควบคู่กับการดึงข้อมูลโพสต์และคอมเมนต์สาธารณะผ่าน Reddit API
การวิเคราะห์ข้อมูลTransformer-based NLP (BERT/Perspective API) ร่วมกับ Hierarchical Regression Analysis

3. ข้อค้นพบสำคัญ (Key Findings)

  • ผู้ที่มีระดับ Narcissism สูงมีแนวโน้มอย่างมีนัยสำคัญในการแสดงออกทางศีลธรรมแบบสั่งสอน (moralistic lecturing) และการแสดงความเดือดดาลทางสังคม (outrage) ในที่สาธารณะ (r = .29, p < .001)
  • ผู้ที่มีระดับ Machiavellianism สูงมีความสัมพันธ์เชิงบวกกับการดำเนินกลยุทธ์ปั่นป่วนทางอารมณ์แบบแนบเนียน และการใช้สำนวนความชอบธรรมทางศีลธรรมมาเป็นเกราะกำบังการโจมตีบุคคลอื่น (r = .34, p < .001)

4. ความเชื่อมโยงกับงานวิจัยชิ้นนี้

งานชิ้นนี้เป็นหลักฐานเชิงประจักษ์โดยตรงที่สนับสนุนสมมติฐานว่า วาทกรรมความดีงามและภาษาทางศีลธรรมในโลกออนไลน์มักถูกนำมาใช้เป็นเครื่องมือบังหน้าในการกระทำพฤติกรรมเอารัดเอาเปรียบ (Extractive Digital Behavior: EDB) และยืนยันความเหมาะสมของการใช้ Reddit เป็นคลังข้อมูลหลัก
