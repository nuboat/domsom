Two-Study Cross-Cultural Design (Reddit N = 10,000 + Pantip N = 4,250) (Q1 Working Paper / Peer Review)

Weaponized Egalitarian Posturing (WEP)

Discursive Rationalization and Exploitative Interpersonal Relations across Western and Thai Conflict Narratives

Author: Peerapat Asoktummarungsr

H1: Complementary Partial Mediation

WEP exerts a total effect of β = 0.284 (p < 0.001) on EIR, operating through both indirect cognitive licensing (SSA, β = 0.190, VAF = 67.0%) and a significant direct path (β = 0.094).

H2: Rationalized Account Shield

Legitimized Rational Accounts (LRA — "I Have My Reasons" / "เรามีเหตุผลนะ") strongly moderates the WEP → SSA path (β = 0.248), acting as a cognitive catalyst for moral licensing.

H3: Direct Exploitation Premium

Controlling for mediation, WEP maintains a direct effect of β = 0.094 (p < 0.001), indicating that vocal parity demands exert an immediate leverage effect in interpersonal extraction.

H4: Cross-Cultural Invariance

The structural model replicates across English (Reddit N = 10,000) and Thai (Pantip N = 4,250) dispute corpora (Δβ ≤ 0.032, p_MGA > 0.05), validated via crowd-sourced moral verdicts.
